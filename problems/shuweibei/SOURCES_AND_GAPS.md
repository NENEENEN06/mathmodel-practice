## 二、缺口与原因

官方渠道（nmmcm.org.cn）**只公布当年题目标题**，历史真题以百度网盘外链形式给出（需登录/含广告），并不直接托管 PDF：

| 缺口 | 原因 |
|---|---|
| 2019 / 2020 无原生 PDF | 官网旧赛题页已下线（旧 URL `/index/problem/detail/id/*.html` 现返回 404，Wayback 无快照）；仅存 2021 年做的网页截图存档，故以截图 PDF 收录 |
| 2022 秋季赛/国际赛（A/B/C/D） | 未见可稳定下载的公开原件；仅 CSDN「2022 数维杯国际挑战赛 C 题 阿尔兹海默症」等解答帖（正文/解答，非题目原件） |
| 2023 春季赛（A/B/C） | 未找到公开原件；CSDN/知乎相关帖多为付费/关注解锁或仅思路 |
| 2023 秋季赛/国际赛（A/B/C/D） | 同上；仅见 A 题（无人机投放）、B 题解答帖 |
| 2024 春季赛/国赛（A/B/C） | 未见公开原件；CSDN 相关帖为思路/代码（付费） |
| 2025 春季赛 B/C | 官方仅给标题；B(C) 原件未在公开仓库找到 |
| 2025 秋季赛/国际赛 A/C/D | 同上 |
| 2021 秋季赛/国际赛 A | 来源仓库本身缺 A 题文件 |
| 2021 春季赛 D | 该年国赛仅 A/B/C 三题（无 D） |
| 各年官方发布 PDF（PDF 原件而非网页/重排） | 平台（赛氪 saikr、模竞 mojinghub、百度网盘）均需登录/付费下载 |

> 说明：英文赛题（国际赛）正文本身不印赛事名，`2021秋-B/C/D`、`2025秋-B`、`2024秋-A/B/C/D` 均据来源仓库目录名（如 `2021_“ShuWei Cup”IMCM_Problem`、`2024_“ShuWei Cup”_Problem`）与题目内容比对确认属数维杯。`2022春-A/B/C.docx` 为据公开全文转载**重排生成**，非官方原件，题目文字与来源一致，已在 manifest 的 `note` 中标注。
