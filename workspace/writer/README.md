## 写作备忘

- 摘要在模型定了之后再写，写不出来说明模型没想清楚。
- 每个结论后面跟一句"为什么可信"。
- 图比文字值钱；但图必须有编号、标题、单位和正文引用。
- 别写"由于时间限制，我们没做…"。
