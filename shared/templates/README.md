# 表格与图表规范

写论文的时候照这个来，省得三个人出的图风格打架。

## 图

- 由代码生成（`shared/models/` 或当次 `code/`），**不贴截图**。
- 分辨率 ≥ 300 dpi，保存为 PNG/PDF；`utils.save_fig()` 已按这个设置。
- 有中文的图必须指定中文字体（`utils.setup_matplotlib()` 已处理）。
- 图题在下、表题在上；坐标轴要有量和单位。
- 一张图只讲一件事；信息多的拆成子图（`plt.subplots(1, 2)`）。

## 表

- 用三线表；数字右对齐、小数点对齐；不要用 Excel 截图。
- 单位写在表头（如 `温度 / ℃`），不要每格重复写单位。
- 表里数字的有效位数全篇统一（通常 3–4 位有效数字）。

## 命名

| 类型 | 命名 | 例子 |
| --- | --- | --- |
| 图 | `fig<问题号>-<内容>.png` | `fig2-灵敏度分析.png` |
| 表 | `tab<问题号>-<内容>.csv` | `tab1-参数取值.csv` |
| 代码 | `model_q<问题号>.py` | `model_q3.py` |
| 数据 | `<来源>-<内容>.csv` | `cumcm2024A-附件1.csv` |

## 排版

- 字体、字号、页边距按当年官方“论文格式规范”来（每年在赛题包里，文件名类似 `format2024.doc`）。
- 公式用 LaTeX 语法；编号连续，正文引用写“式 (3)”。
- 参考文献统一格式，数据来源也要写。
