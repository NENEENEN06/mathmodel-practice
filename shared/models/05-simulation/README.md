# 05 微分方程与仿真

**什么时候来这儿**：题目里的量在"变"——随时间演化、随空间扩散，或者系统本身带随机性，只能模拟出分布再统计。

| 文件 | 内容 | 典型题目 |
| --- | --- | --- |
| `ode_demo.py` | SIR 传染病、阻尼振动、参数辨识 | 疫情传播、动力学控制、药物代谢、温度场 |
| `monte_carlo.py` | 投点估 π、MC 积分、M/M/1 排队、风险仿真 | 排队优化、库存/可靠性、概率风险评估 |

## 建模步骤（跟题目走一遍）

1. **写清状态变量和它的含义**（如 S、I、R 是什么，单位是什么）。
2. **列方程**：用变化率说话（"单位时间新增 = …"），别直接写解。
3. **定参数**：能查到的引文献，查不到的用数据拟合（`ode_demo.fit_ode_params`）。
4. **数值求解**：`solve_ivp`，报出方法与精度设置（RK45 / 误差容限）。
5. **验证**：与已知特例（无感染时的稳态）、守恒量（总人口不变）、或文献结果对照。
6. **灵敏度**：参数 ±10% 看曲线怎么变，这是微分方程题的必答项。

## 坑

- **刚性方程**：参数差几个量级时 RK45 会卡住，换 `method="BDF"` 或 `"Radau"`，或把时间尺度归一化。
- **参数不可辨识**：SIR 的 β、γ 常常只能确定它们的比值或组合，论文里要说明（不要假装两个都准）。
- **仿真要报样本量与置信区间**：只报一个均值没有意义；至少给标准差、95% 分位、以及重复次数。
- **随机数与结果捆绑**：固定种子，报告里写清楚（否则结果不可复现）。
- **排队论仿真在 ρ → 1 附近收敛慢**：多跑几次或延长预热期，别拿一次结果下结论。
- 离散事件仿真（多服务台、复杂规则）建议直接用 `SimPy`（见下），别硬写循环。

## 跑一遍

```bash
python ode_demo.py           # SIR + 阻尼振动 + 参数拟合
python monte_carlo.py        # π / 积分 / 排队 / 风险
```
