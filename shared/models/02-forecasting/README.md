# 02 预测类

**什么时候来这儿**：要给未来一两期（或一段）数值，或者要找"谁在影响结果"。

| 文件 | 模型 | 数据要求 | 擅长 |
| --- | --- | --- | --- |
| `gm11.py` | 灰色预测 GM(1,1) | **4~10 个点**，正数、近似指数增长 | 小样本、贫信息（国赛的经典考点） |
| `arima_demo.py` | ARIMA / SARIMA | 40 个点以上，平稳化后可用 | 有自相关结构、趋势、季节性 |
| `regression_demo.py` | 多元回归 / 岭回归 | 有多个解释变量 | 找影响关系、做因果解释、共线性诊断 |

## 怎么选

- 样本就 5 个点 → GM(1,1)（记得报后验差 C、P，别只报预测值）。
- 时间序列够长、有明显周期性 → SARIMA；先看 ACF/PACF 定阶，或直接 AIC 网格搜索。
- 要解释"为什么" → 回归；自变量打架（共线）→ 岭回归 / 逐步回归。

## 必须做的三件事

1. **划分训练/测试**：留最后 20% 做验证，报出预测误差（MAPE / RMSE），别只报拟合优度。
2. **残差检验**：ARIMA 看 Ljung-Box（p > 0.05 说明残差像白噪声）；回归看残差图是否随机。
3. **灵敏度 / 情景**：参数变一变结论还成立吗？给区间预测比给单点值更专业。

## 坑

- GM(1,1) 只在 |a| < 0.3 时适合中长期；|a| > 0.5 基本别用（`gm11.py` 会直接告诉你）。
- ARIMA 的 d 别乱取：差分成平稳即可，d 太大就把信号差分没了（先跑 ADF 检验）。
- 回归里的 R² 高不代表模型好：可能是共线性或者过拟合，一定看 VIF 和交叉验证。
- 时间序列**不能随机划分**训练集，要按时间前后切，否则信息泄漏、结果虚高。

## 跑一遍

```bash
python gm11.py               # 用小样本序列预测 + 后验差检验
python arima_demo.py         # 自动定阶 + 6 期预测 + 置信区间
python regression_demo.py    # OLS 显著性 + VIF 共线性 + 岭回归
```
