# 竞赛资料（赛制、规则、格式）

写代码之外的事：赛制、时间、评分关注点、官方规则链接。练手前扫一眼，别在格式上丢分。

## 国赛 · 高教社杯全国大学生数学建模竞赛（CUMCM）

| 项 | 内容 |
| --- | --- |
| 主办 | 中国工业与应用数学学会（CSIAM） |
| 官网 | https://www.mcm.edu.cn/ |
| 时间 | 每年 9 月上旬，连续 72 小时 |
| 题量 | 本科组 A / B / C，专科组 D / E，任选一题 |
| 队伍 | 3 人，同一学校；可设指导教师 |
| 提交 | 竞赛管理系统（cumcm.cnki.net）提交论文与支撑材料 |
| 格式 | 每年随赛题发布 `formatYYYY.doc`，**必须按当年版本** |

评分关注：假设合理性、建模恰当性、计算正确性、文字表述清晰程度。

**练手要点**：国赛偏“工程实际问题 + 数据”，评委看重模型是否贴合题目背景、结果是否可信、论文是否自洽。摘要写不好直接掉档。

## 美赛 · MCM/ICM

| 项 | 内容 |
| --- | --- |
| 主办 | COMAP（美国） |
| 官网 | https://www.comap.com/contests/mcm-icm |
| 时间 | 每年 2 月前后，连续 4 天（96 小时左右） |
| 题量 | MCM：A（连续型）、B（离散型）、C（数据型）；ICM：D（运筹）、E（环境/可持续）、F（政策），任选一题 |
| 提交 | 在线提交 PDF，通常限 25 页以内 |
| 语言 | 英文 |

评分关注：Summary Sheet（摘要页）几乎决定第一印象；模型的创造性、论证的严谨性、对题意的理解深度。

**练手要点**：美赛更看重“讲一个完整的故事”，允许简化但要自洽；英文写作与图表表达权重高。

## 数维杯 · 大学生数学建模挑战赛

| 项 | 内容 |
| --- | --- |
| 主办 | 内蒙古创新教育学会 |
| 官网 | https://www.nmmcm.org.cn/ |
| 赛制 | 分秋季赛与春季赛/国际赛，通常 3 天，题目数 2–3 道 |
| 定位 | 难度与国赛接近，偏练手与热身 |

**练手要点**：适合在国赛前当作热身赛打，节奏快、题量小。

## 练手怎么用这份资料

1. 想练真实节奏 → 按对应赛制卡时间（国赛 72h、美赛 96h）。
2. 国赛练“论文自洽 + 结果可信”，美赛练“英文表达 + 故事完整”。
3. 每次练习前把当年的 `format` 文件当成硬约束，别写完再套格式。
