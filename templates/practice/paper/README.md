# 论文（队内写作规范）

## 目录约定

```
paper/
├── paper.tex / paper.docx   源文件（进仓库，方便改）
├── paper.pdf                定稿（对外只交这个）
├── figures/                 图（由 code/ 生成，另存一份到 ../figures/）
└── refs.bib                 参考文献
```

## 结构（国赛 / 美赛通用）

1. **摘要（Abstract）**：问题、方法、结果、结论，一页之内；每个小问都要出现具体结果（数字），不要只写“建立了模型”。
   关键词 3–5 个。
2. **问题重述**：用自己的话重写，别抄题面；点出问题的实际背景与难点。
3. **问题分析**：每个小问的思路、为什么选这个模型（对比过哪些，为什么否掉）。
4. **模型假设**：逐条编号，每条要说明合理性与影响范围。
5. **符号说明**：符号 + 含义 + 单位，全篇统一。
6. **模型建立与求解**：每个小问独立成节；公式编号；写清求解算法与参数取值。
7. **模型检验**：误差分析、灵敏度分析、合理性检验（鲁棒性、极端情况）。
8. **模型评价与推广**：优点、缺点（诚实写）、可推广的场景。
9. **参考文献**：数据来源也要写清（附件里的数据要注明来自赛题附件几）。
10. **附录**：代码（关键片段或全部）、补充数据表。

## 定稿检查表

- [ ] 摘要里有每个小问的具体结果数字
- [ ] 假设、符号、单位全篇一致
- [ ] 所有图表有编号、标题、单位、图例；正文里都被引用到
- [ ] 公式编号连续，变量在正文里都定义过
- [ ] 结果可复现：附录代码 + `code/README.md` 能跑出同样的数
- [ ] 灵敏度分析不只是“变一下还差不多”，要给出变化方向与幅度
- [ ] 无错别字、无截图、无个人隐私信息（学号等出现在封面按赛制要求处理）
- [ ] 只提交 PDF；页数、字体、页边距符合当年赛制文件要求

## 写作提醒

- **先写摘要**（在模型定了之后）：写不出来通常说明模型没想清楚。
- 图比文字值钱：一张能说明问题的图 > 三段解释。
- 别写“由于时间限制，我们没有……”。要么做，要么不提。
- 每个结论后面跟一句“为什么可信”。
